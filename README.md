# AV Cosmetic

A premium cosmetics **trade & wholesale** marketing site — editorial-luxury aesthetic, built with Next.js 14, Tailwind CSS, and Motion.

## Features

- **Multi-page site**: Home, Collection (shop), Product detail, House (about), Trade Notes (testimonials), Inquiries (contact)
- Interactive product gallery with crossfade transitions
- Animated, count-up hero statistics
- Testimonial carousel and brand marquee
- Custom on-brand dropdown and contact form
- Tier-based wholesale pricing on product pages
- Fully responsive, with editorial typography (Fraunces + DM Sans)

## Getting started

```bash
npm install
npm run dev      # http://localhost:3000
```

## Build

```bash
npm run build
npm start
```

## Tech

- [Next.js 14](https://nextjs.org) (App Router)
- [Tailwind CSS](https://tailwindcss.com)
- [Motion](https://motion.dev) for animation
- [lucide-react](https://lucide.dev) for icons
